# Design Pattern: Builder — Session Demo

| Demo | Run |
|---|---|
| [`order-builder/`](order-builder/README.md) | `cd order-builder && ./run.sh` |

Second of nine design-pattern demos (18-26). A small, standalone
example: `Order` gets built as an immutable class with a fluent builder
instead of a telescoping constructor. See the session-level note in
`18-singleton-pattern/README.md` for the `example/`/`exercise/` package
layout used across all nine.

Requires JDK 21+.
