# Java Coding Standards — Session Demos

| Demo | Covers | Run |
|---|---|---|
| [`readability-guidelines/`](readability-guidelines/README.md) | Naming, Method & Class Size, Nulls & Magic Numbers | `cd readability-guidelines && ./run.sh` |
| [`defensive-code-guidelines/`](defensive-code-guidelines/README.md) | Exceptions, Optional, Equals & HashCode | `cd defensive-code-guidelines && ./run.sh` |
| [`modern-java-guidelines/`](modern-java-guidelines/README.md) | Immutability & Records, Streams & Loops, Logging | `cd modern-java-guidelines && ./run.sh` |

These three demos cover the nine "Java Coding Standards" guideline
slides as a set of quick BEFORE/AFTER snippets — three related
guidelines bundled into each demo instead of nine separate ones, since
each guideline on its own is a small, self-contained rule rather than a
principle that needs its own walkthrough. Same `example/`/`exercise/`
package layout as the design-pattern demos (17-25).

Requires JDK 21+.
