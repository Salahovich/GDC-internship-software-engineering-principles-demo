# Anemic vs. Rich Domain Model — Session Demo

| Demo | Run |
|---|---|
| [`order-domain-model/`](order-domain-model/README.md) | `cd order-domain-model && ./run.sh` |

One Java file with its own `main()`, prints a before/after comparison to
the console, and ends with a **~5 minute TODO exercise** for interns to
complete live. See the demo's README for the exercise instructions, a
solution hint, and a discussion of how this relates to Tell, Don't Ask.

Requires JDK 21+.
