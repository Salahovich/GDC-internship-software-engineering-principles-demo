# DRY Principle — Session Demos

Maps to the two slides:

| Slide | Demo | Run |
|---|---|---|
| DRY — Explanation | [`explanation/`](explanation/README.md) | `cd explanation && ./run.sh` |
| DRY — Pitfall | [`pitfall/`](pitfall/README.md) | `cd pitfall && ./run.sh` |

Each demo is one Java file with its own `main()`, prints a before/after (or
correct/broken) comparison to the console, and ends with a **~5 minute
TODO exercise** for interns to complete live. See each demo's README for
the exercise instructions and a solution hint.

Requires JDK 21+.
