# Design Pattern: Visitor — Session Demo

| Demo | Run |
|---|---|
| [`order-item-pricing/`](order-item-pricing/README.md) | `cd order-item-pricing && ./run.sh` |

Ninth and last of nine design-pattern demos (17-25). A small, standalone
example: pricing an order's items without an instanceof chain, using
double dispatch instead. See the session-level note in
`17-singleton-pattern/README.md` for the `example/`/`exercise/` package
layout used across all nine.

Requires JDK 21+.
