# SOLID (L) — Liskov Substitution — Session Demo

| Demo | Run |
|---|---|
| [`discount-policies/`](discount-policies/README.md) | `cd discount-policies && ./run.sh` |

Third of the five SOLID demos (12-16), continuing the `DiscountPolicy`
abstraction from [`13-solid-ocp/`](../13-solid-ocp/README.md) and showing
what happens when a new implementation satisfies the interface but
breaks its behavioral contract.

One Java file with its own `main()`, prints a before/after comparison to
the console, and ends with a **~5 minute TODO exercise** for interns to
complete live. See the demo's README for the exercise instructions and a
solution hint.

Requires JDK 21+.
