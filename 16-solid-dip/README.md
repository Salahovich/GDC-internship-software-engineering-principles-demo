# SOLID (D) — Dependency Inversion — Session Demo

| Demo | Run |
|---|---|
| [`order-notifications/`](order-notifications/README.md) | `cd order-notifications && ./run.sh` |

Last of the five SOLID demos (12-16, and the last session in the whole
repo). It returns to the `OrderNotifier` first introduced in
[`12-solid-srp/`](../12-solid-srp/README.md) and fixes the one coupling
problem it still had, closing the SOLID series.

One Java file with its own `main()`, prints a before/after comparison to
the console, and ends with a **~5 minute TODO exercise** for interns to
complete live. See the demo's README for the exercise instructions and a
solution hint.

Requires JDK 21+.
