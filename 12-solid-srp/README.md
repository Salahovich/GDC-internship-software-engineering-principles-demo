# SOLID (S) — Single Responsibility — Session Demo

| Demo | Run |
|---|---|
| [`order-responsibilities/`](order-responsibilities/README.md) | `cd order-responsibilities && ./run.sh` |

First of the five SOLID demos (12-16). All five share the same
`Order`/`OrderItem` entities, redeclared in each file, so the letters
read as one connected system rather than five unrelated snippets — see
[`16-solid-dip/`](../16-solid-dip/README.md) for how it closes.

One Java file with its own `main()`, prints a before/after comparison to
the console, and ends with a **~5 minute TODO exercise** for interns to
complete live. See the demo's README for the exercise instructions and a
solution hint.

Requires JDK 21+.
