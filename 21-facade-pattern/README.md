# Design Pattern: Facade — Session Demo

| Demo | Run |
|---|---|
| [`checkout-facade/`](checkout-facade/README.md) | `cd checkout-facade && ./run.sh` |

Fifth of nine design-pattern demos (17-25). A small, standalone example:
three subsystems (inventory, payment, notifications) get wrapped behind
one `CheckoutFacade` method. See the session-level note in
`17-singleton-pattern/README.md` for the `example/`/`exercise/` package
layout used across all nine.

Requires JDK 21+.
