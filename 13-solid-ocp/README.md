# SOLID (O) — Open/Closed — Session Demo

| Demo | Run |
|---|---|
| [`order-discounts/`](order-discounts/README.md) | `cd order-discounts && ./run.sh` |

Second of the five SOLID demos (12-16), continuing the `Order`/`OrderItem`
entities from [`12-solid-srp/`](../12-solid-srp/README.md) and introducing
the `DiscountPolicy` abstraction reused by the next two letters.

One Java file with its own `main()`, prints a before/after comparison to
the console, and ends with a **~5 minute TODO exercise** for interns to
complete live. See the demo's README for the exercise instructions and a
solution hint.

Requires JDK 21+.
