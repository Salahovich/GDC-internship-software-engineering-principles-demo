# Design Pattern: Observer — Session Demo

| Demo | Run |
|---|---|
| [`order-confirmation-events/`](order-confirmation-events/README.md) | `cd order-confirmation-events && ./run.sh` |

Eighth of nine design-pattern demos (17-25). A small, standalone example:
once more than one thing needs to react to a confirmed order, a
publisher/listener setup replaces a class that calls each reaction by
name. See the session-level note in `17-singleton-pattern/README.md` for
the `example/`/`exercise/` package layout used across all nine.

Requires JDK 21+.
